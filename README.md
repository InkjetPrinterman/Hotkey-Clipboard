# Hotkey-Clipboard
A windows tray program that helps you designate hotkeys to copy and paste selected text. 

Unpack ZIP and double click the Application. 

Press CTRL+ALT+R to begin recording (6 second window) a hotkey with a modifier (CTRL+L, or SHIFT+M for example, whatever you like). 

Working on setting hotkeys with multiple keys (CTRL+L, L, K for example)

Windows will interrupt the hotkey record when copying from elevated (running in Administrator) windows. Run HotkeyClipboard as administrator to override this.
